# CPA Manager Plus v1.12.6-maintained.1

> [中文 ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.6-maintained.1/docs/release-notes/v1.12.6-maintained.1-zh.md)

## Overview

v1.12.6-maintained.1 updates the maintained self-hosted variant to upstream v1.12.6 while preserving the Bun-only release chain, plugin capability gate, write-only CPA Management Key boundary, saved-key proxy IP stripping, and browser-local CPA/sub2api tool.

## Highlights

- Includes upstream v1.12.6 secure CPA connection migration, provider-aware quota presentation, Codex history continuity, and quota-window recovery.
- Makes Manager data snapshot restore crash-transactional across SQLite, WAL, SHM, rollback journal, and `data.key`, with deterministic startup recovery.
- Bounds startup history detection and Codex legacy identity checks; ambiguous or missing immutable identity now fails closed.
- Scopes plan filters by provider and fences quota activation/cycle relationships to the current generation.
- Keeps `usage_events` as the authoritative event ledger. Derived-data rebuilds do not delete events; bounded compatibility migrations may update documented normalized or response-metadata columns in place.
- Makes Release reruns fail closed when the exact tag already has a GitHub Release, so existing assets are never overwritten.
- Preserves failed/success grouping in usage-monitoring correction rollups.

## Upgrade Notes

- Stop Manager Server before using `manager-data-snapshot restore`; interrupted restores recover automatically on the next snapshot command or Manager Server startup.
- Preserve the SQLite file set and `data.key` together in backups.
- Account actions, automatic disabling, and quota cooldown remain disabled in this maintained variant.
