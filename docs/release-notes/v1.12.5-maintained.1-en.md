# CPA Manager Plus v1.12.5-maintained.1

> [中文 ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.5-maintained.1/docs/release-notes/v1.12.5-maintained.1-zh.md)

## Overview

v1.12.5-maintained.1 refreshes the maintained self-hosted variant to upstream v1.12.5 while preserving the local plugin capability gate, browser-local conversion tools, Bun-only release chain, write-only CPA Management Key boundary, and privileged saved-key proxy IP isolation.

## Highlights

- Includes upstream Codex account identity continuity, OAuth re-login synchronization, Monitoring revision fencing, and immutable `auth_account_id_snapshot` migration.
- Prevents successful-response headers from being persisted as an empty failure body.
- Keeps the CPA Management Key out of browser-readable configuration responses; blank updates continue to preserve the configured secret.
- Keeps caller IP headers out of the privileged Manager Server hop that substitutes the saved CPA Management Key, preventing upstream IP-ban contamination.
- Preserves the self-hosted plugin capability gate, local CPA/sub2api tools, telemetry-free production boundary, and Bun-only build and Release workflow.

## Upgrade Notes

- Manager Server automatically adds `auth_account_id_snapshot` and rebuilds affected derived projections from immutable usage events.
- Create and verify a consistent SQLite online backup and preserve WAL/SHM forensic copies plus `data.key` before deployment.
- Account actions, automatic disabling, and quota cooldown remain disabled.
