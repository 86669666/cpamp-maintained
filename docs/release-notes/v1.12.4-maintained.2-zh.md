# CPA Manager Plus v1.12.4 Maintained 2

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.4-maintained.2/docs/release-notes/v1.12.4-maintained.2-en.md)

## 概览

v1.12.4-maintained.2 将 maintained 去商业化分支同步到上游 v1.12.4，并保留本地转换工具、插件能力门禁、无遥测约束和 Full Mode 本地数据服务。该发布用于自托管 CPA 环境，不包含上游商业注册、联盟标记或托管服务依赖。

## 主要内容

- 同步上游 v1.12.4 的 Request Monitoring Provider 作用域账号身份修复、Codex OAuth 连续性修复及 SQLite WAL 恢复修复。
- 保留 CPA 与 sub2api、Session Auth 等纯本地转换工具；转换逻辑不发送网络请求。
- 当后端返回 `X-CPA-Support-Plugin: 0` 时，插件导航、路由、配置字段和动态资源入口保持关闭。
- maintained Lightweight 构建只生成单文件 `management.html`，同时输出源提交、构建版本和 SHA-256 元数据。
- Full Mode Manager Server 支持本地 SQLite 请求历史、统计和迁移；CPA Management Key 加密存储。

## 升级说明

- Lightweight 部署可原子替换 `management.html`。
- Full Mode 部署前必须一致性备份 `usage.sqlite`、WAL、SHM 和 `data.key`。
- 账号自动操作、自动禁用和 quota cooldown 在生产 maintained 部署中继续由环境变量锁定为关闭，升级不会自动启用。
- 本发布不要求修改 CPA 配置；后端插件硬禁策略保持独立生效。
