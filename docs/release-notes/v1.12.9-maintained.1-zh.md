# CPA Manager Plus v1.12.9-maintained.1

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.9-maintained.1/docs/release-notes/v1.12.9-maintained.1-en.md)

## 概览

v1.12.9-maintained.1 将 maintained 自托管版本同步至上游 v1.12.9，同时保留 Bun-only 发布链、插件能力门禁、CPA Management Key 只写边界、保存密钥代理的客户端 IP Header 隔离，以及浏览器本地 CPA/sub2api 工具。

## 主要内容

- 合入上游 v1.12.9 的 Codex 成员身份语义：匹配成员加上可信 workspace 证据，并通过 `QueryContext` 解析历史账号。
- 保留大历史索引与时序回归测试；官方测试文件补齐 `AccountSnapshot` 与 `strings` 导入后才能编译并 fail-closed。
- 恢复官方 reauth 窗口断言（`2/35` 再 `3/75`）。旧 fork 期望 `1/30` 与 `2/70` 是相对官方成员身份的假回归。
- 保留 usage-monitoring 五维 `failed` 分组：成功与失败事件即使其它维度相同也必须分开 rollup。
- 相同 tag 已存在 GitHub Release 时发布流程直接 fail closed，绝不覆盖已有资产。

## 升级说明

- 上线前必须创建并验证 SQLite 在线一致性备份，同时保存 WAL/SHM 取证副本与 `data.key`。
- 备份必须同时保存 SQLite 文件集与 `data.key`。
- 账号自动操作、自动禁用与 quota cooldown 继续保持关闭。
