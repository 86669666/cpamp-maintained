# CPA Manager Plus v1.12.9-maintained.1

> [中文 ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.9-maintained.1/docs/release-notes/v1.12.9-maintained.1-zh.md)

## Overview

v1.12.9-maintained.1 updates the maintained self-hosted variant to upstream v1.12.9 while preserving the Bun-only release chain, plugin capability gate, write-only CPA Management Key boundary, saved-key proxy IP stripping, and browser-local CPA/sub2api tool.

## Highlights

- Includes upstream v1.12.9 Codex member-identity semantics: matching member plus trusted workspace evidence, resolved through `QueryContext`.
- Keeps the large-history index and timing regression. The official test file needs `AccountSnapshot` plus a `strings` import or it does not compile / fail-close.
- Restores the official reauth window assertion (`2/35` then `3/75`). The stale fork expectation (`1/30` then `2/70`) is a false regression against official member identity.
- Preserves five-way `failed` grouping in usage-monitoring rollups so otherwise identical successful and failed events stay separate.
- Makes Release reruns fail closed when the exact tag already has a GitHub Release, so existing assets are never overwritten.

## Upgrade Notes

- Create and verify a consistent SQLite online backup before promotion, and keep WAL/SHM forensic copies plus `data.key`.
- Preserve the SQLite file set and `data.key` together in backups.
- Account actions, automatic disabling, and quota cooldown remain disabled in this maintained variant.
