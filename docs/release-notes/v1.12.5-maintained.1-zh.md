# CPA Manager Plus v1.12.5-maintained.1

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.5-maintained.1/docs/release-notes/v1.12.5-maintained.1-en.md)

## 概览

v1.12.5-maintained.1 将 maintained 自托管版本同步至上游 v1.12.5，同时保留本地插件能力门禁、浏览器本地转换工具、Bun-only 发布链、CPA Management Key 只写边界，以及保存密钥代理请求的客户端 IP 隔离。

## 主要内容

- 合入上游 Codex 账号身份连续性、OAuth 重新登录同步、Monitoring revision fencing，以及不可变 `auth_account_id_snapshot` 数据迁移。
- 修复成功响应头被错误写入空失败正文的问题。
- CPA Management Key 继续不出现在浏览器可读配置响应中；空输入继续保留已配置密钥。
- Manager Server 使用保存的 CPA Management Key 进行特权代理时继续隔离调用方 IP Header，避免上游 IP ban 污染。
- 保留自托管插件能力门禁、本地 CPA/sub2api 工具、无遥测生产边界和 Bun-only 构建发布工作流。

## 升级说明

- Manager Server 会自动新增 `auth_account_id_snapshot`，并从不可变 usage events 重建受影响的派生投影。
- 上线前必须创建并验证 SQLite 在线一致性备份，同时保存 WAL/SHM 取证副本与 `data.key`。
- 账号自动操作、自动禁用与 quota cooldown 继续保持关闭。
