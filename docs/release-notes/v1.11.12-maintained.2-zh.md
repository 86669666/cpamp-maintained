# CPA Manager Plus v1.11.12-maintained.2

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.11.12-maintained.2/docs/release-notes/v1.11.12-maintained.2-en.md)

## 概述

本维护版收口旧 CPAMC 退役后的正式发布链：GitHub Release 直接构建受维护的 Lightweight 单文件面板，发布完整来源元数据与校验清单，并在发布前后重复核验标签指向、源码提交和制品摘要。

## 主要变更

### 发布来源与制品

- 正式 Release 改为调用 `scripts/build-maintained-lightweight.sh`，拒绝脏工作树、被忽略的环境文件和未授权的 Vite 环境注入。
- Release 同时发布 `management.html`、`metadata.json`、`SOURCE_COMMIT`、`SHA256SUMS` 与原生包；下载后的发布任务再次校验摘要和来源字段。
- 真实标签发布在构建和发布阶段都重新获取远端标签，并要求标签提交、`GITHUB_SHA`、`SOURCE_COMMIT` 和 metadata 完全一致。

### 维护分支边界

- 私有维护仓采用 `main` 单一发布源，不再错误依赖不存在的 `dev` 分支拓扑。
- 移除对上游 `seakee` DockerHub/GHCR 命名空间的发布任务，避免私有仓令牌无法写入上游命名空间而阻塞 GitHub Release。
- Dry-run 仅创建本地临时标签，不上传 GitHub Release 或发送 Telegram 通知。

### 回归门禁

- 根目录测试入口现覆盖完整 Web 与仓库级测试，包括 CPA/sub2api `type=apikey` 转换、插件 fail-closed、架构边界和 Release 工作流完整性。
- 新增 maintained-main 标签拓扑测试，并锁定发布工作流不得重新引入上游容器命名空间。

## 升级说明

- 此版本仅改变维护仓的发布与证据链，不停止或替换正在运行的 CPA Manager Plus Full Mode 服务。
- `usage.sqlite`、`data.key`、管理密钥和服务二进制的既有备份/恢复边界保持不变。
