# CPA Manager Plus v1.12.4 Maintained 2

> [中文 ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.4-maintained.2/docs/release-notes/v1.12.4-maintained.2-zh.md)

## Overview

v1.12.4-maintained.2 refreshes the maintained de-commercialized branch to upstream v1.12.4 while preserving local conversion tools, plugin capability gating, the no-telemetry boundary, and the local Full Mode data service. It is intended for self-hosted CPA environments and does not depend on upstream commercial registration, affiliate markers, or hosted services.

## Highlights

- Includes upstream v1.12.4 fixes for provider-scoped Request Monitoring identity, Codex OAuth continuity, and SQLite WAL recovery.
- Preserves the CPA-to-sub2api and Session Auth local conversion tools; conversion execution performs no network requests.
- Keeps plugin navigation, routes, configuration fields, and dynamic resource entry points disabled when the backend returns `X-CPA-Support-Plugin: 0`.
- The maintained Lightweight build produces a single `management.html` with source commit, build version, and SHA-256 metadata.
- Full Mode Manager Server provides local SQLite request history, statistics, and migration support with encrypted CPA Management Key storage.

## Upgrade Notes

- Lightweight installations can atomically replace `management.html`.
- Full Mode installations must take a consistent backup of `usage.sqlite`, WAL, SHM, and `data.key` before upgrade.
- Account actions, automatic disabling, and quota cooldown remain environment-locked off in the maintained production deployment; upgrading does not enable them.
- No CPA configuration change is required; backend plugin lockdown remains independently enforced.
