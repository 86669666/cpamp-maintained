# CPA Manager Plus v1.12.6-maintained.1

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.6-maintained.1/docs/release-notes/v1.12.6-maintained.1-en.md)

## 概览

v1.12.6-maintained.1 将 maintained 自托管版本同步至上游 v1.12.6，同时保留 Bun-only 发布链、插件能力门禁、CPA Management Key 只写边界、保存密钥代理的客户端 IP Header 隔离，以及浏览器本地 CPA/sub2api 工具。

## 主要内容

- 合入上游 v1.12.6 的 CPA 连接安全迁移、provider-aware quota 展示、Codex 历史连续性和 quota window 恢复。
- Manager 数据快照恢复现在覆盖 SQLite、WAL、SHM、rollback journal 与 `data.key` 的进程崩溃事务，并在启动时确定性恢复。
- 启动历史检测与 Codex legacy identity 检查改为有界查询；缺失或矛盾的不可变身份一律 fail closed。
- Plan 筛选按 provider 隔离，quota activation/cycle 关系严格限制在当前 generation。
- `usage_events` 继续作为权威事件账本。派生数据重建不会删除事件；有界兼容迁移仍可能原地更新已说明的规范化字段或响应元数据字段。
- 相同 tag 已存在 GitHub Release 时发布流程直接 fail closed，绝不覆盖已有资产。
- 保留 usage-monitoring correction rollup 的成功/失败分组。

## 升级说明

- 使用 `manager-data-snapshot restore` 前停止 Manager Server；恢复中断后会在下一次快照命令或 Manager Server 启动时自动修复。
- 备份必须同时保存 SQLite 文件集与 `data.key`。
- maintained 版本继续关闭账号自动操作、自动禁用与 quota cooldown。
