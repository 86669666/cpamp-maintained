# CPA Manager Plus v1.12.10-maintained.1

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.10-maintained.1/docs/release-notes/v1.12.10-maintained.1-en.md)

## 概览

v1.12.10-maintained.1 将自托管 maintained 变体同步到上游 v1.12.10，同时保留 Bun-only 发布链、插件能力门禁、CPA Management Key 只写边界、保存密钥代理 IP 隔离，以及浏览器本地 CPA/sub2api 工具。

## 要点

- 合入上游 v1.12.10（`1ae656c82990c480f3f104326a08c6e0001eeb4c`），overlay revision 仍为 3。
- Lightweight 面板与 Full Mode 控制面继续对插件启用 fail-closed。
- usage-monitoring 继续按成功/失败五维分组，避免 silently drop `failed`。
- 相同 tag 已存在 Release 时流程直接失败，绝不覆盖资产。
- 跟随官方删除 `AGENTS.md`；maintained 基线钉在 v1.12.10。

## 升级说明

- 切产前必须做 SQLite 在线备份并校验，同时保留 WAL/SHM 取证副本和 `data.key`。
- SQLite 文件集与 `data.key` 必须一起备份。
- 账号自动操作、自动禁用和 quota cooldown 继续保持关闭。
- 提升顺序：后端 → Lightweight `management.html`（不重启 CLIProxyAPI）→ Full Mode。
