# CPA Manager Plus v1.12.4-maintained.4

> [中文 ->](https://github.com/seakee/CPA-Manager-Plus/blob/v1.12.4-maintained.4/docs/release-notes/v1.12.4-maintained.4-zh.md)

## Overview

v1.12.4-maintained.4 is the production-fix release for the v1.12.4 maintained branch. It preserves the de-commercialized, self-hosted, plugin-gated, telemetry-free, and local Full Mode data boundaries while completing the Bun-only build and release path.

## Highlights

- The Manager Server container now uses pinned Bun 1.3.14 with `bun.lock` and `bun install --frozen-lockfile`; it no longer depends on npm or the removed package-lock.
- GitHub Actions PR classification, Release preflight, and repository scripts now execute with Bun, backed by workflow-integrity regression tests.
- Maintained Lightweight continues to publish a single `management.html` plus source commit, version, and SHA-256 provenance metadata.
- Full Mode retains local SQLite request history and statistics with encrypted CPA Management Key storage; account actions, automatic disabling, and quota cooldown remain off by default.
- Backend plugin lockdown remains independently enforced; the frontend exposes plugin entries only when backend capability is explicit.

## Upgrade Notes

- Lightweight may atomically replace `management.html`; keep the previous file as an immediately usable rollback.
- Full Mode must take a consistent backup of `usage.sqlite`, WAL, SHM, and `data.key` and verify that the backup is readable before deployment.
- No CPA configuration change is required; production remains loopback-bound behind the existing reverse proxy and Management Key.
- Account actions, automatic disabling, and quota cooldown are not enabled by this upgrade.
