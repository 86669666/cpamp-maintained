# CPA Manager Plus v1.12.10-maintained.1

> [中文 ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.10-maintained.1/docs/release-notes/v1.12.10-maintained.1-zh.md)

## Overview

v1.12.10-maintained.1 updates the maintained self-hosted variant to upstream v1.12.10 while preserving the Bun-only release chain, plugin capability gate, write-only CPA Management Key boundary, saved-key proxy IP stripping, and browser-local CPA/sub2api tool.

## Highlights

- Includes upstream v1.12.10 (`1ae656c82990c480f3f104326a08c6e0001eeb4c`) on overlay revision 3.
- Keeps plugin enablement fail-closed in the Lightweight panel and Full Mode control plane.
- Preserves five-way `failed` grouping in usage-monitoring rollups so otherwise identical successful and failed events stay separate.
- Makes Release reruns fail closed when the exact tag already has a GitHub Release, so existing assets are never overwritten.
- Follows official deletion of `AGENTS.md`; maintained provenance pins remain on v1.12.10.

## Upgrade Notes

- Create and verify a consistent SQLite online backup before promotion, and keep WAL/SHM forensic copies plus `data.key`.
- Preserve the SQLite file set and `data.key` together in backups.
- Account actions, automatic disabling, and quota cooldown remain disabled in this maintained variant.
- Promote backend first, then Lightweight `management.html` (no CLIProxyAPI restart), then Full Mode.
