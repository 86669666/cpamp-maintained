# CPA Manager Plus v1.12.4-maintained.6

> [English ->](https://github.com/86669666/cpamp-maintained/blob/v1.12.4-maintained.6/docs/release-notes/v1.12.4-maintained.6-en.md)

## 概览

v1.12.4-maintained.6 是 v1.12.4 maintained 分支的安全修复发布。它保留去商业化、自托管、插件门禁、无遥测与 Full Mode 本地数据边界，补齐 Bun-only 构建发布链路，并关闭 Full Mode 向浏览器返回 CPA Management Key 的秘密边界。

## 主要内容

- Manager Server 容器改用固定 Bun 1.3.14，通过 `bun.lock` 与 `bun install --frozen-lockfile` 构建前端，不再依赖 npm 或已删除的 package-lock。
- GitHub Actions 的 PR 分类、Release 预检和仓库脚本统一由 Bun 执行，并增加自动化完整性回归测试。
- maintained Lightweight 继续输出单文件 `management.html`、源提交、版本及 SHA-256 来源元数据。
- Full Mode 继续使用本地 SQLite 请求历史与统计，CPA Management Key 加密存储且对浏览器保持只写：GET/更新响应只返回 `managementKeyConfigured`，空输入保留现有密钥。账号自动操作、自动禁用和 quota cooldown 默认保持关闭。
- 后端插件硬禁策略保持独立生效；前端仅在后端显式声明插件支持时暴露对应入口。

## 升级说明

- Lightweight 可原子替换 `management.html`，替换前保留可直接回滚的旧文件。
- Full Mode 上线前必须一致性备份 `usage.sqlite`、WAL、SHM 和 `data.key`，并验证备份可读取。
- 本发布不要求修改 CPA 配置；生产部署继续使用回环监听、反向代理和既有 Management Key。
- 账号自动操作、自动禁用和 quota cooldown 不会因升级自动启用。
